What Can I Do For You?

AI Auto-Generated Tags

When saving a webpage, intelligently generate relevant tags without manual categorization. Say goodbye to tedious folders!

Semantic Search

Don't worry if you can't remember keywords. Just describe the content in natural language to quickly find your target bookmark.

Custom Filter Rules

Supports filtering by title, tags, URL and more. Easily achieve automatic bookmark categorization for more efficient management.

WebDAV Sync

Automatically sync your bookmark data across devices. Access your collection anytime, anywhere. No more data silos!

Dark Mode

Supports light/dark theme switching. Easier on the eyes at night, providing a comfortable reading and management experience.

Batch Bookmark Management

Select multiple bookmarks at once to modify tags, move or delete. Efficiently handle large numbers of bookmarks and save your time.

Feature Guide

Smart Tag Generation

When saving a webpage, AI automatically analyzes the page content and generates relevant tags, letting bookmarks categorize themselves. No more manual organization needed.

Semantic Search

Search using natural language descriptions. For example, "that deep learning tutorial I was reading". AI helps you quickly locate the target bookmark.

Smart Filter Rules

Set custom filter rules to automatically classify and manage new bookmarks based on title, URL, tags and other conditions.
